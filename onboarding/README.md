# Lab member onboarding

This folder contains onboarding templates for incoming members of the Mizumoto Lab.

## Process

Incoming members receive a link to a private Google Sheet containing a tailored onboarding checklist. Individualized onboarding records must not be stored in this public repository.

When day-to-day supervision is delegated to another lab member, the checklist should normally be shared with the student, Nobu, and the day-to-day supervisor.
