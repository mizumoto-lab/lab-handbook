# Graduate student onboarding

This folder contains the onboarding templates for incoming members in the Mizumoto Lab.

## Process

Incoming members will receive a link to a private Google Sheet containing a tailored onboarding checklist. Individualized onboarding records must not be stored in this public repository.

## Files

- `graduate_student_onboarding_template.csv`: Graduate student checklist template.
- `README.md`: This file
